# Smart Queue Management System

## Project Overview

The Smart Queue Management System is a Python-based application designed to manage customer queues efficiently.

The system allows customers to generate tokens, supports priority customers, displays the current queue, serves customers according to priority, searches for tokens, and provides queue statistics.

## Problem Statement

Managing a queue manually can become difficult when there are many customers waiting or when some customers require priority service.

This project provides a simple digital queue management system that organizes customers using tokens and gives priority customers preference while serving.

## Features

- Generate normal customer tokens
- Generate priority customer tokens
- Display the current queue
- Serve the next customer
- Priority-based customer serving
- Search for a token
- Track served customers
- Display queue statistics
- Estimate waiting time
