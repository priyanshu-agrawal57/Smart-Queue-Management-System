# Project Statement

## Project Title
Smart Queue Management System

## Problem Statement

Managing queues manually can be time-consuming and inefficient, especially when there are many people waiting for a service. Traditional queue systems may require users to stand in physical lines and can make it difficult to track the current queue status.

The Smart Queue Management System is designed to provide a simple command-line-based solution for managing people in a queue. The system allows users to add people to the queue, serve the next person, view the current queue, and check the queue status.

## Scope of the Project

The project focuses on implementing a basic queue management system using Python and fundamental problem-solving concepts.

The system provides operations for:
- Adding a person to the queue
- Serving the next person
- Viewing the current queue
- Checking the queue status
- Handling invalid operations and empty queues

The project is intended as a command-line application and does not require a graphical user interface or external database.

## Target Users

The system can be used as a basic queue-management solution for situations such as:
- Small service counters
- College or school offices
- Help desks
- Reception counters
- Other situations where people need to be served in order

## High-Level Features

1. **Add to Queue**  
   Allows a new person to be added to the end of the queue.

2. **Serve Next Person**  
   Removes and serves the person at the front of the queue.

3. **View Queue**  
   Displays the people currently waiting in the queue.

4. **Queue Status**  
   Provides information about the current number of people waiting.

5. **Input Validation and Error Handling**  
   Handles invalid inputs and operations performed when the queue is empty.
